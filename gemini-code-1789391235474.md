> **Project:** AedesAlert AI Public Health & Telemedicine Dashboard  
> **Target Experience:** Preemptive Dengue Outbreak Forecasting, Surgical Strike Dispatch Mapping & Community Reporting  
> **Document Version:** 2.0.0 (Vercel Production Architecture)  

---

## 1. Executive Summary & Core Concept

This specification outlines the technical architecture, library selection, system design, and directory layout for **AedesAlert AI**—a telemedicine and public health platform designed for seamless deployment on **Vercel**. 

AedesAlert AI shifts dengue public health intervention from a reactive hospital-admission model (14-day response lag) to a **48-hour preemptive action loop**. By correlating micro-climate signals (humidity spikes and rainfall indices) with community-submitted mosquito breeding site imagery, the platform forecasts pre-hatch surges 14 days before patient presentation.

## 2. Tech Stack Selection

| Layer | Technology | Purpose & Rationale |
| :--- | :--- | :--- |
| **Framework** | **Next.js (App Router)** | Optimized for Vercel edge deployment, providing SSG/SSR for fast dashboard load times and unified API handling.[cite: 5, 6] |
| **Styling & UI** | **Tailwind CSS + Framer Motion** | Implements the brand design system using **Barangay Navy (`#1A2238`)**, **Alert Coral (`#E63950`)**, **Forecast Teal (`#2EC4B6`)**, and **Cloud White (`#F7F8FA`)**.[cite: 5, 6] |
| **Mapping Engine** | **Leaflet.js (`react-leaflet`)** | Lightweight, high-performance GIS mapping engine for rendering anonymized barangay-level risk heatmaps and surgical strike dispatches.[cite: 5, 6] |
| **State Management** | **Zustand** | Ultra-lightweight global state store to synchronize weather forecasts, breeding-site reports, and map filter layers without unnecessary re-renders.[cite: 5, 6] |
| **Icons & Assets** | **Lucide React** | Clean, accessible SVG iconography for health telemetry, alert levels, and dispatch actions.[cite: 5, 6] |
| **Serverless API** | **Vercel Edge Functions (`/app/api`)** | Node.js serverless micro-endpoints handling risk calculations, weather telemetry ingestion, and dispatch routing.[cite: 5, 6] |
| **Database & Storage** | **Firebase / Firestore** | Manages user authentication, anonymized household reports, photo uploads, and FCM (Firebase Cloud Messaging) push alerts.[cite: 5, 6] |
